# AHC049

## 考察

- とりあえず端から順に運び出すが、その途中で一緒に運び出せるものがあれば運び出す
- 遠くにある箱の方が一緒に運び出せるものが途中にある可能性が高い
- 逆に一番入口に近いものは一緒に運び出すものがないため、入り口までの経路までに箱がない方が効率が悪くなる
  - つまり遠くの箱から運び出した方がよい
- 箱の上に乗せるのは重い箱より軽い箱の方がまとめて運び出せてよい
- 逆に重い箱の上に重い箱を置くと、上に置いた重い箱の耐久力が無駄になる
- 乗せ方の考察
  - 右下じゃなく、耐久力高めから取る？基本的に耐久力高めは、重いのでそうしやすい
  - 耐久力高めを乗せて、少し戻って乗せるのが最適な場合はありそう
  - 少し戻るを入れないと、耐久力低めの右下の方にあるのは、1個ずつ運ぶ必要が出てきそう
    - 1個ずつ運ぶのをなくすのはかなり効きそう
  - 耐久力高めに重いのを乗せるより、重い(耐久力高め)を基本一番下にした方がよさそう
  - 複数乗せるには、途中がいい重さ、耐久力にする必要がある
- 耐久力が高い箱から処理するのはv1よりすべてスコア悪化
- 各運び出しをビームサーチ
  - 最初の箱を選択
  - 右下から見ていき次に運べる箱を探す
  - 評価関数: 乗せた箱の(i+j)*2
